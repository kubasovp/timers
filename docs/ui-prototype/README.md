# UI Prototype (HTML)

Status: Draft  
Owner: github.com/kubasovp  
Last reviewed (UTC): 2026-07-01
Scope: Быстрый браузерный макет экранов MVP без привязки к финальной реализации

## Цель

Этот прототип служит lightweight-макетом для проверки:
- структуры экранов Focus/Timers/Reminders;
- доступных пользовательских действий;
- ключевых UI-состояний, которые должны быть синхронизированы с доменными state machine.

## Что внутри

- `index.html` — единый макет рабочего пространства с тремя панелями.
- `styles.css` — простая стилизация для читаемости.

## Как использовать

1. Открыть `index.html` в любом браузере.
2. Обсуждать изменения UX напрямую в HTML/CSS.
3. При уточнении логики обновлять связанные документы:
   - `docs/02-functional-overview.md`
   - `docs/open-items.md`
   - state machine артефакты (когда будут выделены в отдельные файлы).

## Ограничения

- Не production UI.
- Нет интерактивной логики и привязки к данным.
- Возможны расхождения с финальным Vue/Tauri интерфейсом.

## Конвенции для документации

- Использовать `data-context` и `data-state` как якоря для обсуждения сценариев.
- Если добавляется новое состояние в UI, оно должно быть отражено в state machine для соответствующей сущности.
- Для reminders использовать каноничные состояния из `docs/state-machines/reminder.md` (`enabled`, `due`, `snoozed`, `done`, `disabled`, `deleted`).
