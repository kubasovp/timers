## 1.1 Цель системы

**Timers** — локальное desktop-приложение для управления короткими временными сценариями:
- фокус-сессии;
- произвольные таймеры;
- одноразовые и повторяющиеся напоминания.

## 1.2 Ценность

Продукт заменяет три отдельные утилиты одним локальным инструментом, без аккаунта и облака.

## 1.3 MVP-область

Входит в MVP:
- Linux и Windows как основные платформы;
- локальное хранение (SQLite);
- системные уведомления и звуковые сигналы;
- пресеты, базовая история, настройка поведения окна.

Не входит в MVP:
- аккаунты, синхронизация, мобильные клиенты;
- календарные интеграции;
- платёжная модель, AI, веб-версия;
- общий агрегирующий dashboard для всех сценариев;
- runtime-отключение бизнес-модулей; в MVP можно скрывать панели UI.

## 1.4 Роли и заинтересованные стороны

- **Пользователь (единственная роль MVP)** — запускает таймеры/напоминания и управляет ими.
- **Разработчик/владелец продукта** — поддерживает стабильную работу на desktop и эволюцию требований.

## 1.5 Ключевые сценарии

1. Запуск фокус-профиля, управление этапами фокус/перерыв.
2. Быстрый запуск кастомного таймера вручную или из пресета.
3. Создание одноразового/ежедневного/интервального напоминания.
4. Восстановление корректного состояния после сна ОС/перезапуска.
5. Обработка пропущенных напоминаний без «шторма» уведомлений.
